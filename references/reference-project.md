# 参考工程：桌面搭配

该示例保存了一个已完成的贴纸拼贴口播短片的合成方法。源码与示例台词可用于改造新工程；人物、物品图片、音乐和字体文件由使用者自行准备。

## 示例规格

- 合成输出：1080×1920、30 fps、811 帧，约 27.03 秒。
- 人物母片：480×854、24 fps、约 27.07 秒，带原声的纯绿幕口播。
- 镜头：0—23.167 秒为盘腿抱电脑的全身，之后为近景。
- 主题元素：台灯、杯子与木杯垫、绿萝、空白牛皮纸卡片。

这些数值描述参考案例。新主题从真实音频与素材建立自己的时间轴。

## 输入布局

```text
project/
├── assets/
│   ├── take.mp4           # 自行提供的人物母片
│   ├── presenter.png      # 人物参考图
│   ├── items_sheet.png    # 白底四宫格元素图
│   └── words.json         # 当前口播的转写时间点
├── fonts/                # 项目实际使用的中文字体
├── build/                # 抠图、音频与渲染中间文件
└── scripts/              # 从参考源码改造的实际入口
```

`source-manifest.json` 记录媒体规格和待准备文件，不包含任何账号的私有素材编号。准备工程时复制的参考时间点位于 `reference-project/assets/words.json`；替换台词后应重新转写。

## 改造要点

1. `render.py` 的输出规格、`SRC_FPS=24`、`NFRAMES=811`、`T` 及正文中的局部时点、镜头位置，都需要随真实素材调整。
2. 物品键名 `lamp/coaster/pothos/card`、咖啡图案与台词属于示例内容。新主题统一映射或重写。
3. `render_all.sh` 默认渲染 811 帧、8 个分片，可通过 `STICKER_RENDER_FRAMES` 和 `STICKER_RENDER_JOBS` 覆盖。它逐一检查子进程与分片帧数，全部成功后才原子替换 `build/picture.mp4`。这些参数须与改造后的渲染器一致。
4. `audio.py` 的时长、音乐路径、响度与淡入淡出应按新工程调整；只保留一份口播。
5. 示例使用 Noto Sans CJK SC、Ma Shan Zheng、ZCOOL KuaiLe、LXGW WenKai。按实际运行环境定位字体并验证中文字符覆盖，字体文件不随仓库分发。
6. 图像合成依赖 numpy、OpenCV、Pillow；物品抠图示例使用 rembg `isnet-general-use`；音频示例依赖 soundfile、pyloudnorm、ffmpeg；最终合成示例使用 `rn`。
7. 白底主题元素与绿幕人物分别处理，保留绿萝等物体的真实绿色，杯子与杯垫作为一个资产。

## 验收经验

参考案例检查过完整解码、转写、响度、绿幕边缘、道具透明度、字形和转场。两项有用的修订是将长标题换行，以及放大并居中结尾人物；另修复了前景物品与光标在转场中残留的问题。新项目要检查自己的结果。
